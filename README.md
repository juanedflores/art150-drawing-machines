# Drawing Machines — ART 150, Fall 2026

A gallery of the 18 vibration-motor drawing machines made in Intro to New Media Art
at UIC, each shown with its written instructions, the machine, and a clip of it drawing.

**Live:** https://juanedflores.github.io/art150-drawing-machines/

## Walkthrough mode (for the hallway display)

Click **▶ Walkthrough** (bottom right) for a full-screen, hands-free tour: each
project's drawing, then the clip of the machine making it, then its other photos.
It ends on the page footer with this gallery's address and a QR code.

- `?walkthrough` starts it automatically on load
- `?walkthrough&loop` repeats it forever (for a kiosk browser)
- While it runs: `Esc` exits, `←` / `→` skip projects, `Space` pauses

Timings are at the top of `walkthrough.js`.

Copied from the course site
(https://github.com/juanedflores/Intro-to-New-Media-Arts, `content/Assignments/Drawing_Bot/gallery/`).
